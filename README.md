# Brief Viborder para Vercel

Incluye:
- Diseño adaptado a la identidad del logo (rojo, negro, blanco).
- Imagen/logo ya incluida en el proyecto como `logo-viborder.jpg`.
- Formulario que envía a WhatsApp solo los campos contestados.
- Las preguntas van normales y las respuestas en negritas.

## Publicación
1. Sustituye los archivos del proyecto por estos.
2. Haz commit en GitHub.
3. Espera el redeploy automático en Vercel.
